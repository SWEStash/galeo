# Contributing to galeo

galeo is maintained by SWEStash and isn't open to outside contributions yet, so pull requests
aren't accepted for now.

Feedback is welcome:

- **Bugs**: [open an issue](https://github.com/SWEStash/galeo/issues/new). Say what you did,
  what you expected and what happened, and include your OS and galeo version.
- **Feature requests and ideas**: open an issue that describes the problem you want solved.
- **Security problems**: don't open a public issue. Report it privately through
  [GitHub's security advisories](https://github.com/SWEStash/galeo/security/advisories/new).

Working on the code yourself? See [`docs/development.md`](docs/development.md).
