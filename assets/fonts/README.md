# Vendored fonts

Variable fonts shipped with the app, so nothing is fetched at run time. Each family keeps its
SIL Open Font License 1.1 text next to it.

| Family | Version | Files | Source |
|---|---|---|---|
| Inter | 4.1 | `InterVariable.woff2`, `InterVariable-Italic.woff2` (`web/` in the release) | https://github.com/rsms/inter/releases/tag/v4.1 (`Inter-4.1.zip`, sha256 `9883fdd4…6b11e`) |
| Source Serif 4 | 4.005R | `SourceSerif4Variable-{Roman,Italic}.ttf.woff2` (`VAR/`) | https://github.com/adobe-fonts/source-serif/releases/tag/4.005R (`source-serif-4.005_WOFF2.zip`, sha256 `af10e80d…abd28`) |
| JetBrains Mono | 2.304 | `JetBrainsMono[wght].ttf`, `JetBrainsMono-Italic[wght].ttf` (`fonts/variable/`), renamed `-Variable` | https://github.com/JetBrains/JetBrainsMono/releases/tag/v2.304 (`JetBrainsMono-2.304.zip`, sha256 `6f6376c6…f7bbf`) |

JetBrains Mono publishes its variable font only as TTF.
