Accept; optional length bound below. **I4** *Add to dictionary* calls `session.defaultSession.addWordToSpellCheckerDictionary`. galeo runs every profile in one session, so a word learned in one profile is learned in all of them. Packaged builds also resolve no host (`MAP * ~NOTFOUND`). The strace suite is Linux only, so no test watches the Windows path. Accept. **I6** The site's `site.js` frames `demo/` from the same origin with no `sandbox` attribute (CSP `frame-src 'self'`). A script running in the demo could rewrite the parent's install commands (key URL, fingerprint). Getting one there needs a way past the demo's `script-src 'self'`, Trusted Types and the sanitizer. A demo script could already `window.open('/')` and script that same-origin page, so framing adds nothing. A `sandbox` without `allow-same-origin` would give the demo an opaque origin, which breaks its workers. Accept, as T23. |

## Attack surface delta (since v0.9.0)

| Entry point | Trust boundary | Controls verified |
|---|---|---|
| `documents.paste` (new channel) | renderer → main; writes the clipboard's text into the page | Schema `z.tuple([documentId])` (`schemas.ts:101`); handler needs the sender's **edit grant** for that id **and** an input credit (`input.spend`, from `before-input-event` in `window/factory.ts:64`); then `webContents.fromId(sender).paste()`, Chromium's own paste into the focused element of **the sender's** window. The page never reads the clipboard (`clipboard-read` stays denied, `policy.ts:4-6`); returns only a boolean. A page can't paste on its own or into another window |
| `documents.spellingMenu` (new event) | main → renderer | Carries `{ id }` of the active tab only, never the word. The renderer opens the menu only if its own spell-checked `.cm-content` let a right-click through in the last 2 s (`DocumentView.tsx` `takeSpellingClick`), once per click |
| `context-menu` on every `webContents` (`index.ts:363`) | Chromium → main | `isEditable` only; at most 5 suggestions; keyed by `contents.id`, deleted on window close (`cleanups`), consumed by the next menu, 2 s freshness. I3 |
| Document menu spelling entries (`menus.ts`) | main | Only while the tab is in edit mode (`grants.allows`); suggestion picked by index into main's own copy (`SUGGESTION = /^spelling-(\d)$/`), never text from the page; spelling choices return `null`, so they grant **no** input credit (unlike *Save*); the tab-moved check (`path !== tab.path`) runs before any action |
| `webPreferences.spellcheck: true` (`policy.ts:46`) | all windows | `<html spellcheck="false">` (`renderer/index.html`), so only the editor marks words: `EditorView.contentAttributes` `spellcheck="true"` in edit mode while the setting is on (`source-view.ts:146`). Settings fields and the find bar stay off (e2e `spell-check.spec.ts:145`). The session's checker stays off until a profile turns the setting on, after `ready` (session defaults would otherwise undo it) |
| Spell-check network | app → network | Linux: shipped dictionary, no download (measured). Windows/macOS: system checker; download base on `galeo:` (404); resolver rules. I5 |
| Vendored `en-US-10-2.bdic` | upstream data → every Linux package | SHA-256 `b0d80e6b6c5491879365e176ecbd98074602a663429bcfcfb0a5a8375c051f13` = the value in `docs/dependencies.md` (Chromium `deps/hunspell_dictionaries` at `00f6e69c`); `*.bdic binary` in `.gitattributes`; `extraResources` under `linux:` only; `verify:package` fails unless the packaged file is **byte-identical** to `assets/`. L1 (a): `scripts/audit-shipped-dev.mjs`, run after the `--omit=dev` step in `ci.yml`, `release.yml` and
`preflight.sh` (all Linux):

```js
// Electron and electron-builder are devDependencies, yet Electron is every package's runtime and electron-builder
// writes the installers' scripts: an advisory of their own fails on high, as a shipped dependency's does (SR-10).
// Advisories they only inherit (minimatch, picomatch) stay with the build-tool gate.
import { execFileSync } from 'node:child_process';

const SHIPPED = ['electron', 'electron-builder', 'app-builder-lib'];
let output;
try {
  output = execFileSync('npm', ['audit', '--json'], { encoding: 'utf8', maxBuffer: 64 * 1024 * 1024 });
} catch (error) {
  output = error.stdout; // npm audit exits 1 when it finds anything
}
const report = JSON.parse(output);
if (report.error) {
  console.error(`audit: ${report.error.summary}`); // an outage must not read as a pass
  process.exit(1);
}
const found = SHIPPED.flatMap((name) =>
  (report.vulnerabilities?.[name]?.via ?? [])
    .filter((via) => typeof via === 'object' && (via.severity === 'high' || via.severity === 'critical'))
    .map((via) => `${name}: ${via.severity} ${via.url}`),
);
if (found.length > 0) {
  console.error(found.join('\n'));
  process.exit(1);
}
console.log(`audit: no high or critical advisory of their own in ${SHIPPED.join(', ')}`);
```
