## Attack surface delta (since v0.5.1)

| Entry point | Trust boundary | Controls verified |
|---|---|---|
| `documents.toggleTask(id, line, base)` | renderer → main; **writes a file without edit mode** | zod tuple (line an integer 1..1e8, base ≤ 256 characters); the record looked up in the sender's window, the Settings tab and a tab in edit mode refused, an article format only, an input credit spent (`src/main/documents/handlers.ts`); the file's hash equal to `base`, main's own parse of the fresh text in the task worker, an anchored flip pattern, the exact round trip (L1), `saveDocument` checking `base` again (`src/core/documents/task-boxes.ts`) |
| `documents.missingLinks(id)` | renderer → main; file system `stat` | only the links of the text main read itself; `classifyLink` refuses UNC, device, `/net` and other schemes; at most 500 links, 4 at a time (I1); answers hrefs only, no content (`src/core/documents/links.ts`) |
| Callouts | render worker, after the sanitizer | five fixed types, only galeo's own classes, a constant title, nothing from the content but its text (`src/renderer/worker/pipeline/callouts.ts`) |
| Front matter fields | render worker, after the sanitizer | keys and values as text nodes (`src/renderer/worker/pipeline/frontmatter.ts`) |
| Change marks | renderer memory | baselines in a per-window map, 2 M characters per document and 16 M per window, never written anywhere (SR-16); the diff bounded by `scanLimit` and `timeout` (`change-marks.ts`, `change-ranges.ts`) |
| Marks and task boxes in the page | renderer | constant strings through `classList`, `setAttribute` and `title`; no new HTML sink (the only new `innerHTML` is in a test) |

Nothing changed in the preload, window creation, CSP, sessions or fuses: SR-01, SR-02, SR-06 and SR-08 carry
over. Both new channels are in `CHANNELS` and `requestSchemas`, so SR-11's sender and frame checks apply.

## Per-SR verification (SRs the delta touches)

- **SR-02/SR-03 content is inert — PASS.** Callouts and front matter run after the sanitizer and add no attribute,
  URL or script; the callout icons are galeo's own CSS `data:` SVG masks.
- **SR-09 engine updates — PASS after M1.**
- **SR-10 supply chain — PASS with I3** (accepted).
- **SR-11 minimal, validated IPC — PASS.** Two channels, each zod-validated, scoped to the sender's window.
- **SR-12 capability-scoped file access — PASS after L1/L2.** Ticking: input credit, main's own parse, `base`,
  exact round trip; the T6 residual (a compromised page can flip a task box in any file open in its window, once
  per real input) is the one ADR-031 accepts. Broken links: only paths the read document names, existence only.
- **SR-14 bounded work — PASS after I1.**
- **SR-15 safe saves — PASS.** A tick saves through `saveDocument` (atomic, symlinks and hard links as before);
  a missing file is a conflict, so a tick never creates one.
- **SR-16 local metadata — PASS.** Change-mark baselines stay in renderer memory.
- **Accessibility (not an SR)**: Tab in edit mode keeps a way out (Esc then Tab, Ctrl+M; WCAG 2.1.2), described to
  screen readers.
