# Guide for coding agents

Read these before working in galeo, in this order:

1. [docs/development.md](docs/development.md): commands, [How we work](docs/development.md#how-we-work) (issues, claiming, what counts as done, releases, and what an agent may do without approval), [Before pushing](docs/development.md#before-pushing), the conventions and the change checklist.
2. [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) and the ADRs in [docs/decisions/](docs/decisions/): how the app is built and why. An accepted ADR is changed only by a new ADR that supersedes it.
3. [docs/security/threat-model.md](docs/security/threat-model.md): the SR-xx requirements are acceptance criteria.
4. [docs/RELEASING.md](docs/RELEASING.md) and [docs/VALIDATION.md](docs/VALIDATION.md) when a release or a manual check is involved.

What an agent may do without asking, and what needs the maintainer's approval, is in How we work → *Agents*.
